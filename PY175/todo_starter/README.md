Todo List Tracker Application
- create & use todolists: add todos, mark complete, mark all done, delete, track remaining todos left
- edit todolists: change title, delete
- error handling: searching for list or todo that doesn't exist, unique todolist title, title and todos are in range 1-100 
- lists are displayed in alphabetical order and the completed lists are moved to bottom of page
- some javascript confirmation dialog for dangerous (irreversible) actions: deleting lists/todos, marking all todos in a list as complete
